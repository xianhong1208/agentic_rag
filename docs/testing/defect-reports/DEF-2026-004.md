# DEF-2026-004:`_load_config` 吞掉 FileNotFoundError,與 docstring 不符

## 1. 環境
`src/config/config_manager.py::_load_config`(約 L145-158)。

## 2. 前置條件
以不存在的路徑呼叫 config 載入。

## 3. 重現步驟
1. `get_config("config/not_exist.yaml")`。

## 4. 預期結果(依 docstring)
拋出 `FileNotFoundError`,啟動流程大聲失敗。

## 5. 實際結果
`raise` 位於 try 區塊內被 `except Exception` 捕捉吞掉,呼叫端拿到 `None`
與空 `_config`——設定檔路徑打錯時服務可能以空設定靜默啟動,錯誤延後爆發。

## 6. 佐證
`tests/test_config.py` 檔案不存在案例(行為快照);程式碼審視。

## 7. 根因分析
例外處理範圍過寬(`except Exception` 包住了主動 `raise`)。

## 8. 處置 / 修復
待修:把「檔案不存在」檢查移出 try,或 `except Exception` 前先
`except FileNotFoundError: raise`。修復時翻轉測試斷言。
