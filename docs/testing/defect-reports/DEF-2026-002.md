## 1. 環境
`src/domain/exceptions.py:76`(`FolderNotFoundError`)、`:184`(`QueryExecutionError`)。

## 2. 前置條件
呼叫端以 `folder_id=0` 建構例外(目前 DB folder id 從 1 起算,故實務上未觸發)。

## 3. 重現步驟
1. `FolderNotFoundError(folder_id=0)`。
2. 觀察 message / details。

## 4. 預期結果
identifier 應為 `0`(`is not None` 判斷)。

## 5. 實際結果
- `FolderNotFoundError`:`folder_id if folder_id else folder_name` → identifier 變 `None`。
- `QueryExecutionError`:`if folder_id:` → `folder_id=0` 不寫入 details。

## 6. 佐證
`tests/test_exceptions.py` 相關案例;SPEC-exceptions 第 4 節備註。

## 7. 根因分析
truthiness 判斷應為 `is not None` 判斷。

## 8. 處置 / 修復
待修:兩處改 `if folder_id is not None`。低風險純防禦性修正;修復時補 `folder_id=0` 斷言。
