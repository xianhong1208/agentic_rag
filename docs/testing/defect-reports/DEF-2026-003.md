## 1. 環境
`src/config/config_manager.py`;README「設定驅動」「配置覆寫優先順序」章節。

## 2. 前置條件
`config.yaml` 內含 `${VAR:-default}` 形式的佔位符。

## 3. 重現步驟
1. 在 config.yaml 寫 `database_url: ${DATABASE_URL:-postgresql://localhost/rag}`。
2. 設定環境變數 `DATABASE_URL`,啟動服務。

## 4. 預期結果(依 README)
佔位符展開為環境變數值(或 default)。

## 5. 實際結果
config 層僅 `yaml.safe_load`,全 src/、main.py、app.py、scripts/ 均無
expandvars / envsubst 邏輯;佔位符以**字面字串**進入 config。

## 6. 佐證
`tests/test_config.py` 以「`${VAR:-default}` 字面保留」行為快照鎖定;
`grep -rn 'expandvars|envsubst' src/ main.py app.py` 無結果。

## 7. 根因分析
README 描述的是目標設計(與 MCP_Center 對齊),展開邏輯尚未實作;
目前部署以「直接寫值 + `.env`」運作,故未爆發。

## 8. 處置 / 修復
二擇一:(a) 在 `_load_config` 讀檔後、`yaml.safe_load` 前做 `${VAR:-default}` 正則展開,
並補對應 REQ/TC;(b) 修正 README,將此列為規劃中功能。README 已暫加註(見 commit)。
